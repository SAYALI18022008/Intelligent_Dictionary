INTELLIGENT DICTIONARY — WARM CREAM & FOREST GREEN EDITION

FILES
- index.html: clean dictionary interface and word management
- style.css: warm cream, forest green, sage and muted gold design
- script.js: Trie data structure, prefix search, suggestions, add/delete, localStorage, and statistics

RUN
1. Keep all three files in the same folder.
2. Open index.html in a modern browser (or use VS Code Live Server).
3. Search prefixes such as app, learn, garden, pre, trans, or any other letters.
4. Suggestions update as you type. Press Enter or click a suggestion to record a search.
5. Use Word tools to add or delete a word.
6. Search the Dictionary field to find saved words; the full list is not shown automatically.

NOTES
- The starter vocabulary contains more than 2,000 unique words.
- Added words, deletions, and search frequencies are saved in this browser's localStorage.
- Your changes persist across reloads in the same browser on the same device.
- This version removes the separate Explore the Trie/tree panel and Copy Tree feature while keeping the core Trie-powered prefix search.
- The app uses a real Trie. Deleting a word preserves branches shared by other words.
